# Non-Negotiable Development Model

This is the imported higher-level development standard relevant to serious repo work.

## Core principle
Development does not advance on vibes.

Work counts as progress only when it is:
- executed
- verified
- documented
- handed off cleanly

## Default project structure
- `TODO.md` = control surface
- `phases/` = detailed execution docs
- tasks = work
- gates = proof
- phases do not pass until gates pass

## Required phase concepts
Each serious phase should define:
- goal
- scope
- status
- tasks
- gates
- pass criteria
- evidence
- assumptions
- blockers / open questions
- next phase dependency

## Non-negotiable rules
- tasks are not gates
- no phase advancement without gate closure
- verification beats intuition
- separate truth layers
- mark assumptions explicitly
- preserve handoff quality
- use evidence for gate closure
- map reads before writes
- writes require extra controls
- assume rate limits are real until disproven
